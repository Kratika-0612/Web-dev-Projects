# Student Dashboard

A responsive student dashboard built using HTML and Tailwind CSS to display academic information and provide quick access to useful sections.

## Features

* Academic statistics
* Subject cards
* Quick-action buttons
* Responsive grid layout
* Hover effects and styling

## Technologies Used

* HTML5
* Tailwind CSS

## Purpose

Created to practice utility-first CSS, responsive layouts, and interactive UI design.
